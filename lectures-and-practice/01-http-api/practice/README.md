# Практика 01: HTTP API

В этой практике реализован HTTP-сервис на Go: собственные маршруты, OpenAPI-спецификация с генерацией роутера и middleware для логирования запросов.

## Запуск

Нужен Go 1.23 или новее.

```bash
go generate ./...
go mod tidy
go test ./...
go run ./cmd/server
```

По умолчанию сервер слушает `http://localhost:8080`. Адрес задаётся переменной `HTTP_ADDR`.

## Маршруты

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/health` | `{"status":"ok"}` |
| GET | `/items` | Статический список элементов |
| GET | `/items/{id}` | Элемент или JSON-ошибка с HTTP 404 |

Спецификация находится в `api/openapi.yaml`. Команда `go generate` обновляет роутер в `internal/api/api.gen.go`. Обработчики расположены в `internal/httpapi`, middleware подключается в `internal/app`.

Тесты проверяют успешные ответы, 404 и запись метода, URI и кода ответа в лог.
