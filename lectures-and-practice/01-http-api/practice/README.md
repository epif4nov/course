# Практика 01: HTTP API

Небольшой HTTP-сервис на Go закрывает три шага практики:

1. собственный сервер и маршруты;
2. OpenAPI-контракт, генерация маршрутов и статические endpoints;
3. middleware с методом, URI, HTTP-статусом и длительностью запроса.

## Запуск

Нужен Go 1.23 или новее.

```bash
go generate ./...
go mod tidy
go test ./...
go run ./cmd/server
```

Сервер слушает `http://localhost:8080`. Адрес можно задать переменной `HTTP_ADDR`.

## Маршруты

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/health` | `{"status":"ok"}` |
| GET | `/items` | Статический список элементов |
| GET | `/items/{id}` | Элемент или JSON-ошибка с HTTP 404 |

Спецификация находится в `api/openapi.yaml`. Команда `go generate` генерирует Go-маршрутизатор в `internal/api/api.gen.go`; обработчики остаются в `internal/httpapi`. Middleware подключается к роутеру в `internal/app`.

Тесты проверяют успешные ответы, ошибку 404 и наличие в логе метода, URI и кода ответа.
